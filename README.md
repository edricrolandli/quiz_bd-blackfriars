# Mesin Analitik Blackfriars

Quiz game praktikum Basis Data: *Malam yang Berulang di Blackfriars* (London, 1891).

Repo ini hanya berisi "mesin" game (tampilan, ilustrasi, dan PostgreSQL yang berjalan di browser lewat PGlite).
Cerita lengkap, soal, kunci jawaban, dan data mahasiswa disimpan di server, tidak di repo ini.

- `vendor/pglite/` — [PGlite](https://github.com/electric-sql/pglite) 0.5.16, lisensi Apache 2.0 (lihat `vendor/pglite/LICENSE`).
